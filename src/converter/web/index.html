关于

「万能转换」是一个运行在你电脑上的本地文件转换服务，由 Java + FFmpeg 驱动， 支持视频 / 音频互转（含 m3u8）、图片 ⇄ PDF、PDF ⇄ Word、Excel ⇄ CSV 等常用转换。 页面上的转换都在浏览器所在电脑完成，上传的文件 24 小时后自动清理。

手机访问：确保手机与电脑连同一 Wi-Fi，用浏览器打开服务启动时显示的局域网地址即可。
